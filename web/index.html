Blindfetch

To read a memo, a Zcash light wallet asks its server for the transaction by txid. That one request tells the server which payment is yours. Blindfetch answers the same request over PIR: the wallet gets the transaction, and the server cannot tell which one it sent.

How it works

  1. The server keeps every transaction with a shielded output since Ironwood activation. Proofs and signatures sit outside the txid (ZIP 244, ZIP 229), so it zeroes them and stores each transaction at about a fifth of its mined size, with the same txid.
  2. It packs them into 32 KiB rows and answers YPIR queries over the rows. YPIR is the PIR scheme ZODL uses for shielded voting, from the Zellic-audited valar-ypir crate.
  3. A wallet already knows where its transactions were mined from scanning compact blocks. It downloads the whole index and asks for its rows in rounds of exactly four queries, with dummy queries for random rows shuffled in.
  4. It checks every row it gets back, dummies too, against a hash in the index, and recomputes the txid of each transaction. A server that sends anything wrong is caught and dropped.
