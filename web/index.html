Blindfetch

To read a memo, a Zcash light wallet asks its server for the transaction by txid. That one request tells the server which payment is yours. Blindfetch answers the same request over PIR: the wallet gets the transaction, and the server cannot tell which one it sent.

How it works

  1. The server keeps every transaction with a shielded output since Ironwood activation, with its proofs removed. Proofs are not covered by the txid (ZIP 244, ZIP 229), so what remains still matches the txid exactly.
  2. It cuts them into 4 KiB rows and serves the rows over YPIR, the PIR scheme ZODL uses for shielded voting, from the Zellic-audited valar-ypir crate.
  3. Your wallet already knows where its transactions were mined from scanning compact blocks. It downloads the whole index, finds the rows, and asks for them in rounds of exactly eight queries, filling empty slots with random rows.
  4. It recomputes the txid of what came back. A server that alters a memo or serves the wrong transaction fails that check.
